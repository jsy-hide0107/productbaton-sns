# ProductBaton 나레이션 스타일 가이드 v1.0 (2026-11-26)

ChatGPT(수영 계정, 기존 대화 기반)와 Claude가 함께 정리. 나레이션은 수영 복제 목소리이므로 수영 말투를 기준으로 한다.

## 정체성
사업과 앱에 관심 많은 사람이, 자기가 발견한 흥미로운 이야기를 시청자에게 설명한다.
뉴스 진행자, 자기계발 강사, 광고 성우처럼 말하지 않는다.

## 규칙 5개
1. 질문보다 사실로 시작한다. ("알고 계셨어요?" X → "당근은 원래 판교 직장인만 쓸 수 있는 앱이었어요.")
2. 연결 문장에도 정보를 넣는다. ("그런데 문제가 생깁니다" X → "문제는 판교 직장인만 쓸 수 있었다는 거예요.")
3. 감동보다 인과관계. 문제 → 원인 → 판단 → 행동 → 결과. 확인 안 된 인과는 만들지 않는다.
4. 짧은 문장, 한 문장에 정보 하나. 어미는 ~였어요 / ~거든요 / ~거죠 / ~한 겁니다를 섞는다. ~했습니다만 반복 금지(뉴스 톤).
5. 마지막에 교훈·감동을 억지로 넣지 않는다.

## 지양 표현 (정보 없이 분위기만 만들 때)
여러분 알고 계셨나요? / 놀라운 사실은 / 그런데 문제가 생깁니다 / 하지만 이야기는 여기서 끝나지 않습니다 /
세상을 바꾼 작은 아이디어 / 운명을 바꾼 단 한마디 / 모든 것을 뒤바꾼 결정 / 결국 성공의 비결은 / 단순한 ○○를 넘어

## 비율
수영 말투 80% + 쇼츠용 정보 공개 순서·긴장감 20%. 맥락까지 잘라 건조해지지 않게.

## 검수 체크
- 수영이 실제로 말할 법한 문장인가, 소리 내어 읽어도 자연스러운가
- 지워도 의미가 안 바뀌는 문장이 있는가
- 결과뿐 아니라 이유가 있는가
- 검증 안 된 숫자·인과·과장이 있는가
- 교훈을 강요하는가

## 1·2편 판정 (ChatGPT)
- 당근 훅 "알고 계셨어요?" 5/10 → "당근은 원래 판교 직장인만 쓸 수 있는 앱이었어요."
- "그런데 문제가 생깁니다" 3/10 → "근데 문제는 이용할 수 있는 사람이 너무 한정적이었다는 거예요."
- 당근 엔딩 "결국 사용자 한마디" 4/10 → "사용자 요청을 반영하면서, 직장인만 쓰던 앱이 동네 주민도 쓰는 앱으로 바뀐 거죠."
- 토스 훅 8/10 (가장 수영 말투에 가까움)
- 토스 엔딩 "실패가 알려준 건 하나" 6/10 → "이번엔 접근을 바꿨어요. 만들고 싶은 서비스보다 사람들이 실제로 불편한 문제에 집중한 거죠. 그게 송금이었어요."

## CTA (통일)
"직접 만든 앱을 소개하고 싶다면 DM 주세요."

## 운영 방향 (합의)
- 콘텐츠 비중: 유명 앱 비화 60% / 1인 개발자·신생 앱 30% / 앱 매각·수익화 10%
- 영상 10개를 첫 마일스톤 → 그때 1인 개발자 10~20명에게 '무료 소개 영상 제작 + 원본 제공' 제안 (채널 노출이 아니라 영상 결과물을 무료로 주는 제안)
- 무료 협업 3건 → 유료 상품. 팔로워 1만보다 첫 유료 고객 1명이 우선.
- 지표: 첫 3초 유지율, 평균 시청 비율, 공유·저장, 프로필 방문, 개발자 DM, 영상당 제작 시간
- 역할 분리: Claude = 제작, ChatGPT = 사실 검증·사업성 평가. 같은 대본을 두 AI가 반복 수정하지 않는다.
- 벤치마크: 신비한 건축사전(포맷), 소비더머니(갈등·반전 구성), EO Korea(창업자 판단 중심), 비하인드로직(직접 경쟁), 29CM 브랜드코멘터리(이야기→판매 연결)
